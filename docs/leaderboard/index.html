FormulaCode Leaderboard

Performance of frontier LLM agents on repository-level code optimization, compared against human expert patches. Updated monthly.

Metrics

RP

RP Rank

Ranked Pairs position computed over pairwise advantage comparisons across all agent-model configurations. Lower is better.

Adv

Advantage

Speedup_agent − Speedup_expert. Measures performance relative to human experts. A positive value means the agent outperformed the human.

Ã

Normalized Advantage

Signal-to-noise ratio of the agent advantage, accounting for variance across workloads. Rewards consistent improvements across many benchmarks.

S

Speedup

Geometric mean of per-workload speedup ratios (baseline / agent execution time). Values > 1 indicate the agent made the code faster.
