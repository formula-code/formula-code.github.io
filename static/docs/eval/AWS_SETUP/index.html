    AWS SETUP

    AWS Account Setup (Recommended)¶

    1) Making a .env file¶

    Copy the contents of .env.template to .env, then add/override the variables below.

    # LLM credentials (pick one path)
PORTKEY_API_KEY=...
# Required when using Portkey-routed calls in fceval/llms/portkey_llm.py
PORTKEY_MAX_TOKENS=200000
# ANTHROPIC_API_KEY=...
# OPENAI_API_KEY=...

# AWS auth/region
# Credentials use the default AWS SDK/CLI credential chain
# (env keys, instance role, shared config, etc.).
AWS_REGION=us-east-1
# AWS_ACCESS_KEY_ID=...
# AWS_SECRET_ACCESS_KEY=...
# AWS_SESSION_TOKEN=... # only for temporary credentials

# Required for --remote-build
EC2_INSTANCE_TYPE=c5ad.large
EC2_USE_NVME_STORAGE=true

# Common remote-build tuning
# EC2_ROOT_VOLUME_SIZE=100
# EC2_INSTANCE_AMI=ami-...
# EC2_AVAILABILITY_ZONES=us-east-1a,us-east-1b
# SPOT_PRICE=0.25
# Security groups are auto-created per instance at launch.
# No EC2_SECURITY_GROUP_IDS env var is used.

# S3 buckets
FC_EVAL_S3_BUCKET=tb-staging-us-east-1
# Optional: stores remote evaluation snapshots (disabled when unset)
# S3_EVALUATION_SNAPSHOTS_BUCKET_NAME=tb-eval-snapshots-us-east-1
# Optional: results upload destination when using --upload-results
# S3_BUCKET_NAME=tb-run-results-us-east-1

# ECR login/preflight discovers registries from compose/Dockerfile image refs.
# No ECR_ACCOUNT_ID/ECR_REGION env vars are used.

# FormulaCode adapter image namespace
DOCKER_HUB_REPOSITORY=formulacode/all

    2) Install AWS CLI and log in¶

    Install AWS CLI v2: 1. macOS (Homebrew): brew install awscli 2. Linux x86_64: curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip" unzip awscliv2.zip && sudo ./aws/install 3. Verify install: aws --version

    Before login, your user identity must already be assigned an AWS account role (or equivalent IAM permissions) that can run fc-eval remote operations. At minimum, the logged-in caller needs the permissions listed in step 6, including iam:PassRole on datasmith-batch-execution-role.

    Login options: 1. AWS SSO (recommended): aws configure sso --profile default then aws sso login --profile default 2. Access keys: aws configure (set keys on default profile) or export AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY / AWS_SESSION_TOKEN.

    Confirm auth: aws sts get-caller-identity

    3) Pick region and credential method¶

    Use either: 1. Default AWS SDK/CLI credential chain (for example, your configured default profile), or 2. Env keys (AWS_ACCESS_KEY_ID + AWS_SECRET_ACCESS_KEY [+ token]).

    Set region explicitly (AWS_REGION preferred). No AWS_PROFILE, EC2_SECURITY_GROUP_IDS, or ECR_* env vars are required by fceval remote runtime.

    4) Create S3 bucket(s)¶

    Minimum for remote build: 1. Staging bucket (for remote transfer): FC_EVAL_S3_BUCKET

    Recommended: 1. Separate snapshots bucket: S3_EVALUATION_SNAPSHOTS_BUCKET_NAME 2. Results bucket (if using --upload-results): S3_BUCKET_NAME

    You can also point all three to one bucket for simplicity.

    5) Create EC2 instance role + instance profile¶

    Important: profile name must currently be datasmith-batch-execution-role unless you patch code.

    1. Create IAM role trusted by ec2.amazonaws.com.
    2. Create instance profile with the same name.
    3. Add role to instance profile.
    4. Attach AmazonSSMManagedInstanceCore.
    5. Attach custom policy for required S3/ECR access.

    Role needs: 1. S3 access to staging/snapshot buckets: s3:GetObject, s3:PutObject, s3:DeleteObject, s3:ListBucket 2. ECR read access if pulling private ECR images: ecr:GetAuthorizationToken, ecr:BatchGetImage, ecr:GetDownloadUrlForLayer, ecr:BatchCheckLayerAvailability

    6) Grant permissions to your local caller (user/role running fceval)¶

    Required for remote EC2 workflow: 1. EC2: DescribeImages, DescribeSubnets, DescribeInstances, DescribeSecurityGroups, RunInstances, TerminateInstances, StopInstances, CreateSecurityGroup, AuthorizeSecurityGroupIngress, DeleteSecurityGroup, CreateTags 2. SSM: DescribeInstanceInformation, SendCommand, GetCommandInvocation 3. S3 on staging/results buckets: GetObject, PutObject, DeleteObject, ListBucket 4. IAM pass role: iam:PassRole on datasmith-batch-execution-role

    If you use interactive remote sessions (fceval tasks interact --remote-build) or SSM tunnel code paths: 1. Also allow ssm:StartSession, ssm:TerminateSession, ssm:ResumeSession.

    If you use FormulaCode ECR helper utilities to publish images: 1. Also allow ECR write actions: ecr:CreateRepository, ecr:DescribeRepositories, ecr:ListImages, ecr:InitiateLayerUpload, ecr:UploadLayerPart, ecr:CompleteLayerUpload, ecr:PutImage, ecr:BatchCheckLayerAvailability, ecr:GetAuthorizationToken, and sts:GetCallerIdentity.

    7) Network requirements¶

    Instances must be able to reach: 1. AWS APIs (SSM, S3, ECR) 2. Package/install endpoints used by user-data bootstrap (Docker Compose download, AWS CLI install)

    If your subnet has no public internet route, provide NAT or relevant VPC endpoints.

    8) Populate .env (example)¶

    AWS_REGION=us-east-1

# Remote EC2 defaults/tuning
EC2_INSTANCE_TYPE=c5ad.large
EC2_USE_NVME_STORAGE=true
EC2_ROOT_VOLUME_SIZE=100
# SPOT_PRICE=0.25
# EC2_AVAILABILITY_ZONES=us-east-1a,us-east-1b

# S3 buckets
FC_EVAL_S3_BUCKET=tb-staging-us-east-1
S3_EVALUATION_SNAPSHOTS_BUCKET_NAME=tb-evaluation-snapshots-us-east-1
S3_BUCKET_NAME=tb-run-results-us-east-1

# SG is auto-created per instance; no EC2_SECURITY_GROUP_IDS env var.
# ECR registry discovery comes from compose/image refs; no ECR_* env vars.

    9) Quick verification¶

    aws sts get-caller-identity
aws s3 ls s3://$FC_EVAL_S3_BUCKET
uv run fceval tasks build -t hello-world --tasks-dir tasks --remote-build

    10) Minimal IAM Audit Commands¶

    Use these to re-check permissions with minimal calls:

    # Caller identity
aws sts get-caller-identity

# EC2 role/profile expected by code
aws iam get-role --role-name datasmith-batch-execution-role
aws iam get-instance-profile --instance-profile-name datasmith-batch-execution-role

# Role policy coverage
aws iam list-attached-role-policies --role-name datasmith-batch-execution-role
aws iam list-role-policies --role-name datasmith-batch-execution-role
aws iam get-role-policy --role-name datasmith-batch-execution-role --policy-name datasmith-s3-inline

# Effective caller inheritance
aws iam list-groups-for-user --user-name <your-iam-user>
aws iam list-attached-group-policies --group-name <group-name>

    If you need interactive remote session:

    uv run fceval tasks interact -t hello-world --tasks-dir tasks --remote-build

    Note: interactive mode uses local aws ssm start-session CLI.
